🔧 Flujo de Escaneo

1. Usuario hace clic en "Escanear" → Abre modal de cámara 2. Sistema solicita permisos de cámara → Muestra vista previa 3. Usuario enfoca código de barras → Detección automática 4. Código procesado → Verifica cache local 5. Si en cache → Carga datos locales inmediatamente 6. Si no en cache → Consulta Open Food Facts API 7. API responde → Extrae datos del producto 8. Datos procesados → Pre-llena formulario 9. Usuario confirma → Producto añadido al inventario 10. Producto cacheado → Disponible para futuras consultas

// Uso básico del módulo scanner class ProductScanner { constructor() { this.scanner = new BarcodeScanner(); } async scanProduct() { try { // Abrir modal de escaneo this.scanner.showScannerModal(); // El escaneo se maneja automáticamente a través de callbacks // Cuando se detecta un código, se llama a handleScanSuccess() } catch (error) { console.error('Error en escaneo:', error); this.showError(error.message); } } async handleScanSuccess(barcode) { // 1. Verificar cache const cached = window.productStorage.getCachedProduct(barcode); if (cached) { return this.addProductFromCache(barcode, cached); } // 2. Consultar API const productData = await this.fetchFromOpenFoodFacts(barcode); // 3. Cachear y añadir window.productStorage.cacheProduct(barcode, productData); this.addProduct(productData); } }
